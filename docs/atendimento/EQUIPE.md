# Equipe do Diretor de Atendimento (índice)

Uma linha por especialista. Perfil = `docs/atendimento/especialistas/<id>.md`. Executor: **restrito** = `especialista-atendimento`; **web** = `especialista-atendimento-web`. Origem (definida na Fase 2/3): ORIGINAL EXTERNO | ORIGINAL + EXTENSÃO LOCAL | AGENTE PRÓPRIO; "a definir" até lá. Estado: **a montar** (perfil ainda não existe) · ativo · em auditoria. O Diretor só convoca quem tem estado ativo; "a montar" = lacuna a informar ao dono.
