# Micro-pack: Não contactar

- **Absoluto** para automação comercial: nenhuma cadência, follow-up, reativação (30/60/90) ou campanha o ultrapassa. Qualquer desenho de automação precisa de uma condição de saída explícita "cliente em Não contactar".
- Entra por **qualquer origem**: botão/ficha, opt-out automático por pedido inequívoco no WhatsApp, "Não tem interesse", troca de status. Mantém o responsável; só bloqueia novas prospecções/automação.
- Cliente em Não contactar que escreve de novo **nunca é reativado sozinho**: gera pendência para decisão humana.
- Fonte da verdade: `docs/BUSINESS_RULES.md` (CLI-9, PRO-5, PRO-8), `lib/do-not-contact-core.mjs`. Não duplicar regra aqui; ler a fonte por Grep.
