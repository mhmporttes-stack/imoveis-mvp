Como deixar a janela trabalhar atrás das outras

Minimizada ela não trabalha (o Facebook não abre conversa). Atrás de outras janelas trabalha se o Chrome for aberto por este atalho:

  1. Feche o Chrome por completo (todas as janelas; se houver ícone do Chrome perto do relógio, clique com o botão direito › Sair).
  2. Botão direito no atalho do Chrome (área de trabalho ou barra de tarefas › botão direito em Google Chrome) › Propriedades.
  3. No campo Destino, depois de chrome.exe", acrescente um espaço e: --disable-features=CalculateNativeWinOcclusion --disable-backgrounding-occluded-windows
  4. OK e abra o Chrome sempre por esse atalho. Aqui deve aparecer "visível" mesmo com a janela atrás das outras.
